# Журнал ручных действий

1. Открыл консоль Яндекс Облака в браузере.
2. Перешёл в Compute Cloud, раздел Виртуальные машины.
3. Нажал «Создать виртуальную машину».
4. В поле «Имя ВМ» ввёл kovalenko-01-web-manual.
5. Нажал «Добавить метку», задал created-by = console.
6. В блоке «Образ загрузочного диска» выбрал Ubuntu 24.04.
7. Зону доступности указал ru-central1-a.
8. В блоке «Диски и файловые хранилища» переключил тип на HDD.
9. Размер диска поставил 15 ГБ.
10. Открыл вкладку «Своя конфигурация» в вычислительных ресурсах.
11. vCPU выбрал 2, гарантированную долю 20%.
12. RAM указал 2 ГБ.
13. Поставил галочку «Прерываемая».
14. Подсеть оставил default, публичный IP — Автоматически.
15. Способ доступа выбрал SSH-ключ, логин student.
16. Вставил публичный ключ id_ed25519.pub, имя ключа kovalenko-01-wsl.
17. Выключил резервное копирование (Cloud Backup).
18. Проверил расчёт стоимости в правой панели.
19. Нажал «Создать ВМ», дождался статуса RUNNING.
20. Скопировал публичный адрес 84.201.131.133.
21. Подключился по SSH командой ssh student@84.201.131.133.
22. На машине выполнил sudo apt update и sudo apt install nginx.
23. Проверил systemctl status nginx, служба active (running).
24. Открыл в браузере http://84.201.131.133, увидел Welcome to nginx!.
25. Выполнил set +H и заменил заголовок страницы через sed.
26. Обновил страницу, увидел labwork on kovalenko-01-web-manual.
